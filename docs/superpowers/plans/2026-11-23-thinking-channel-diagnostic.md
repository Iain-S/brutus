## Design And Bounds

Use saved decision 3 from the exact pinned order archive and installed thinking
model/digest. Keep original comparison order, prompt/system, seed 20261122,
sampling, think=True, 8192 context, 1536 generated tokens and 170-second hard
deadline. Vary only presence of the provider `format` field. Client validation
always requires the exact final-channel ID-only JSON; never salvage thinking.

Four predeclared conditions: schema, omitted, omitted, schema (ABBA). Each pair
is byte-identical. These are explicit diagnostic controls, not automatic retries
or a rerun of the old capability gate. No raised budgets or native environment.
Continue after complete rejected model output; stop on transport/deadline or
receipt failure. Length-limited output is a failed condition, not a valid answer.
Record all attempts and independent raw HTTP evidence, including failures.

Removing only `format` is the smallest useful intervention. Changing templates,
switching endpoints or parsing thinking would confound this comparison. An ABBA
result can support a local schema association but cannot isolate internal server
mechanisms, guarantee determinism or establish model superiority. Official
[structured output](https://docs.ollama.com/capabilities/structured-outputs) and
[thinking](https://docs.ollama.com/capabilities/thinking) references describe the
separate controls/fields; actual behavior must be measured on installed 0.16.2.
