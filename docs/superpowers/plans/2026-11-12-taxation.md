# Native Taxation Capability Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans with TDD and independent source review. Preserve the existing workspace and user-staged models.

**Goal:** Let the planner establish and measure lawful tax collection, not merely change a tax rate with no collectors.

**Architecture:** Add a pure native finance JSON endpoint with collector/house
coverage, cached tax accounting and cumulative native expense counters. Keep
monthly raw tax bases distinct from actual denarii and annual estimates.
Add optional forum placement at existing district anchors and existing tax/wage
actions, without changing the engine, action count or observation ABI. Persist
full finance diagnostics and compare them strictly on independent replay.

**Tech Stack:** C headless shared library, Python ctypes/Gymnasium, unittest,
existing native CTest/GitHub Linux workflow, original-data integration fixture.

## Design And Constraints

Source audit: staffed road-accessible forums or a senate spawn tax collectors;
house coverage is required for native monthly collection. The current planner
cannot place either. Missing income is a capability gap; bankruptcy timing or
trade necessity is not proven. Use forum only for this checkpoint (senate is
not independently required). Keep the four-anchor service-search limitation
explicit. Never inject funds, staffing, coverage or modified house models into
an asset-backed run. Native fixtures may seed isolated state without assets.

No mandatory rate, wage, build order or future financial policy. Diagnostic
queries never collect taxes, recalculate totals, refresh estimates or mutate
native state. Monthly tax bases are not denarii; return native yearly collected
denarii without reconstructing last-collection cash from the current tax rate.
Cached overview totals can lag; expose them as cached, not a current
profit assertion. A covered house can be untaxed if the rate is zero.

Exact last-collection cash is deferred: native state retains raw monthly bases
and annual denarii, not a separately retained last payment with its historical
rate. Do not invent it by applying the current rate. Same-year before/after
annual counter changes and actual treasury/expense changes can measure a period;
cross-year measurement must account for rollover explicitly.

Road diagnosis must use the same pure native map predicate as forum figure
spawning; the generic cached road flag is not maintained by that callback.
Expose both separately. The native `houses_covered` field is service activity
(shared with labor seekers, capped and decayed), not unique current coverage;
label it `houses_covered_activity_cached`. Actual covered population comes from
currently occupied houses with nonzero native tax coverage.
